# Healthcare Risk Prediction - Heart Disease

## Overview
Machine Learning Model for heart attack prediction. Uses pandas for dataframe management, seaborn for visualizations, and sklnearn for model creation and evaluation. 
Power BI Dashboard to come. 

## Tools
Python, Excel, Power BI

## Libraries
Pandas, Seaborn, sklearn, matplotlib.pyplot

## Dataset
Data is from a Kaggle dataset and can be found here: https://www.kaggle.com/datasets/alexteboul/heart-disease-health-indicators-dataset/data
The data has been previously trimmed and cleaned. I utilize python and pandas to explore the data, create models (SVM, logistic, Random Forest), and to prep different data (such as creating order to age buckets and Income Labels) for Power BI Dashboard visualization. 

## Files
- Heart_Attack_data.csv  :  data from kaggle
- HeartAttack_MachineLearning.ipynb  : Jupyter Notebook with script
- HDoA.csv  : transformed data set limited to just those with Heart Disease or Attack
